BitBeast Sprite Tool

Converts between sprites.txt, sprites.h (PROGMEM arrays) and images, and has a pixel editor. Everything runs locally in your browser.

Import

Unknown C arrays get their size from a // NAME 16x16 comment, or from a guess based on the byte count. Tamaguino's arrays import too.

Export

After saving sprites.txt, run python tools/gen_sprites.py. Or save sprites.h straight into BitBeast/. The output is the same either way.
